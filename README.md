1)Скачиваем или берем с архива Office Deployment Tool

https://www.microsoft.com/en-us/download/details.aspx?id=49117

Открываем officedeploymenttool - выбираем диск C и там создаем папку ODT, установщик выгрузит файлы туда
Либо сделать руками на диске C - папку ODT прямо в корне диска.

2)Далее идем в реестр и ищем там CountryCode в HKCU\Software\Microsoft\Office\16.0\Common\ExperimentConfigs\Ecs , там надо установить значение "std::wstring|US" - или любое другое, кроме "std::wstring|RU"

либо

выполнить команду в CMD от имени администратора:
reg add "HKCU\Software\Microsoft\Office\16.0\Common\ExperimentConfigs\Ecs" /v "CountryCode" /t REG_SZ /d "std::wstring|US" /f

3)Идем в генератор XML конфига https://config.office.com/deploymentsettings
Или можно использовать мой из архива Office2024LTSC.xml

там выбираем Архитектура: 32 бита, Продукты для установки: Office LTSC Professional Plus 2024 — Volume License и там ставим галочки на нужных приложениях (Ворд, Эксель, Оутлук и пр.), язык - русский, сеть доставки - по умолчанию оставляем серваки Майков, Выводить экран установки для пользователя, удалить все мси версии пользователя (чтобы не было конфликтов), автоматически принять условия лицухи, везде оставляем КМС, жмем готово и справа вниз скатываемся надо найти кнопку экспорт, выбрав формат Office XML, сайт попросит выбрать имя и папку - папка что создавали на диске С ODT, имя - Office2024LTSC.

4)Возвращаемся в CMD (от имени админа) - там команду:

cd c:\odt

потом:

Setup.exe /configure Office2024LTSC.xml

5) Офис без лицензии но оригинальный с серваков Майков установлен.
Ключики для таких версий стоят по 200-300 Р/1-2-3 бакса.
